# KBC Trivia Game

A Python-based interactive quiz game inspired by **Kaun Banega Crorepati (KBC)**.

The program asks the player multiple-choice questions, provides different options, checks the selected answer, and increases the prize amount for each correct answer. If the player gives a wrong answer, the game ends.

## Features
- Interactive question-and-answer system
- Multiple-choice options
- Prize money progression
- Correct and incorrect answer checking
- Simple Python concepts such as lists, loops, conditions, and user input
